# Wordle

Guess the hidden 5-letter word in 6 tries. Every time you hit **Play** you get a new random word, with no daily limit.

**Play it here:** https://noahfgarrett.github.io/Wordle/

For **Wordle Battle**, pick a number from 1 to 999,999 and have a friend enter the same number. You'll both get the same word. Compare scores to see who solved it in fewer guesses. Use **Share** after a game to copy your `3/6`-style score and the colored square grid. Battle results include the battle number.

- 1,697 common answer words and 12,578 accepted guesses
- On-screen keyboard for phones, plus physical keyboard support
- Stats, streaks and guess distribution saved in your browser
- Hard mode, light theme and a color-blind-friendly palette
- A single self-contained `index.html` with no dependencies
